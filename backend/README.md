# SmartBuy AI — Backend

This repository contains the backend for SmartBuy AI.

Tech stack
- Node.js + TypeScript
- Express
- MongoDB (Mongoose)

Getting started
1. Copy .env.example to .env and fill in variables
2. npm install
3. npm run dev

Structure
- src/
  - controllers/
  - routes/
  - models/
  - services/
  - repositories/
  - middlewares/
  - utils/
  - config/

Docker
- Dockerfile included for containerized deployment.
